# KaffePOS Support SOP

## Kanal support

- WhatsApp bisnis
- Email support
- Form chat / DM bila ada

## Target respon

- Jam kerja: respon awal maksimal 15-30 menit
- Di luar jam kerja: respon awal maksimal 2 jam
- Bug blocker produksi: respon secepat mungkin

## Template tanya awal ke user

1. Nama toko
2. Email akun
3. Nomor WhatsApp
4. Masalahnya apa
5. Kapan mulai terjadi
6. Pakai web atau APK
7. Jika printer: merek / model printer
8. Screenshot / video error

## Kategori tiket

- `AUTH`
- `CHECKOUT`
- `SYNC`
- `PRINTER`
- `BILLING`
- `APK CRASH`

## Alur eskalasi

1. Support kumpulkan bukti
2. Cocokkan ke kategori masalah
3. Jika user masih bisa kerja, berikan workaround
4. Jika user tidak bisa transaksi, naikkan jadi prioritas tinggi
5. Catat hasil akhir dan solusi

## Workaround cepat

### Login / OTP
- minta user cek folder spam
- kirim ulang OTP
- cek apakah email salah ketik

### Printer
- pair ulang printer
- test print
- pindah ke USB bila Bluetooth tidak stabil
- jika mendesak, gunakan fallback browser print dari web

### APK
- tutup paksa lalu buka lagi
- cek internet
- update ke APK terbaru

## Penutupan tiket

Pastikan dicatat:
- akar masalah
- solusi
- apakah perlu follow-up
- apakah masuk daftar bug permanen

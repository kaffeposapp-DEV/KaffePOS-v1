# Kaffee POS — AI Context

## Stack
React 18 + TypeScript + TailwindCSS v3 + Capacitor 6 + Supabase + Zustand

## Konvensi Wajib
- State: Zustand only
- Styling: TailwindCSS className only, no CSS files
- Async: async/await + try/catch
- TypeScript: strict, no any
- Icons: lucide-react only
- Font: Poppins (heading), Inter (body), JetBrains Mono (angka)

## Design System
Selalu baca: design-system/MASTER.md sebelum buat UI apapun

- Jangan install library baru tanpa konfirmasi
- Jangan ubah file di luar scope tugas
- Jangan tulis ulang kode yang tidak berubah

- Jangan pakai emoji di kode
- Jangan pakai h-screen, gunakan min-h-[100dvh]
- Jangan pakai font Fredoka atau Nunito
